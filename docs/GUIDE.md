## Как пользоваться

**Шапка:**

| Кнопка | Что делает |
|---|---|
| 3D, Планы, Участок | Модель, SVG-планы этажей или ситуационный план |
| День, Вечер, Ночь | Время суток |
| Праздник | Лента с бантом, шары, конфетти, салют. Люди собираются в ивент-холле |
| Прогулка | Вид от первого лица |
| Достоверность | Раскраска по источникам: план, фото, видео или достроено |
| Редактор | Правка зон с экспортом в JSON |
| О модели | Источники и пояснения |

**Модель:**

- Вращение — левая кнопка мыши, сдвиг — правая, масштаб — колесо. На телефоне: один палец вращает, два — масштаб и сдвиг.
- Слева рейка уровней. Выбор уровня делает разрез: всё выше прячется.
- Снизу ракурсы: вход, с высоты, холл и турникеты, площадка со статуей, лекторий, лаунж под пирамидой, кластер Tashkent, разрезы 1 и 2 этажа.
- Клик по зоне открывает инспектор: тип, площадь, места, заметка, откуда известно.

**Прогулка:**

| Клавиша | Действие |
|---|---|
| `W A S D` или стрелки | Идти |
| `Shift` | Бег |
| `Пробел` | Прыжок |
| `F` | Полёт сквозь стены |
| `1–4` | Этажи |
| `B` | Атриум −1 |
| `M` | Большая карта |
| `Esc` | Пауза |

Клик по мини-карте переносит в выбранную точку. На телефоне — джойстик и кнопки «Полёт», «Бег», «Прыжок».

**Ссылки:**

| Ссылка | Что откроется |
|---|---|
| `?party` или `#party` | Праздничная версия |
| `?q=low` / `?q=high` | Принудительное качество графики |
| `?people=0` | Без людей |
| `?crowd=2` | Вдвое больше людей |

## Как устроены данные

Всё здание описано в [`src/data/building.js`](../src/data/building.js). Это единственный источник геометрии: поменяли цифры — после перезагрузки страницы модель, планы и коллизии прогулки пересоберутся.

- **Координаты:** `u` вдоль главного фасада (0…55,2 м от южного угла), `v` вглубь (0 — главный фасад), `z` от пола 1 этажа. Пол уровней: B1 −4,5, L1 0, M +2,25, L2 +4,5, L3 +9,0. Сетка колонн 6 × 6 м.
- **Достоверность:** у элементов есть `confidence`. `plan` — снято с поэтажного плана, `photo` и `video` — видно на панорамах и в видео, `inferred` — достроено по логике здания.

| Массив | Что описывает | Конструктор |
|---|---|---|
| `LEVELS` | Уровни: отметка пола и низ перекрытия | — |
| `ZONES` | Помещения-прямоугольники: пол, мебель по типу, подписи, выбор кликом | `Z(level, id, type, name, [u0, v0, u1, v1], extra)` |
| `DESKS` | Ряды столов в кластерах | `rowsU` / `rowsV` |
| `WALLS` | Стены-отрезки | `W(level, u0, v0, u1, v1, kind, extra)` |
| `DOORS` | Двери и проёмы в стенах | `D(level, u, v, width, kind)` |
| `CORES` | Лестничные клетки и лифты | — |
| `STAIRS`, `LANDINGS` | Открытые марши и площадки | `S(...)` |
| `SLAB_HOLES` | Проёмы в перекрытиях | — |
| `FACADES`, `CANOPY`, `ENTRANCE`, `LOGOS` | Фасады, козырёк, крыльцо, знаки «21» | — |
| `LANDMARKS`, `WAYPOINTS`, `SOURCES` | Ориентиры, точки маршрутов, источники | — |

## Рецепты: планировка

### Сдвинуть или переименовать зону без кода

1. Включите «Редактор» и кликните зону.
2. Поменяйте координаты, тип или название и нажмите «Применить». Модель пересоберётся сразу, а правки сохранятся в `localStorage` этого браузера.
3. «Экспорт JSON» выгрузит все зоны. Перенесите нужные значения в `ZONES` в `building.js`, чтобы правка попала в репозиторий.

### Добавить помещение со стенами и дверью

```js
// building.js → ZONES
Z('L2', 'l2-quiet', 'meeting', 'Тихая переговорная', [30.6, 42.6, 36.6, 48.6], { confidence: 'inferred', note: 'Пример' }),

// building.js → WALLS: стекло в чёрных рамах по двум сторонам
W('L2', 30.6, 42.6, 36.6, 42.6, 'g'),
W('L2', 30.6, 42.6, 30.6, 48.6, 'g'),

// building.js → DOORS: дверь 1 м в середине нижней стены
D('L2', 33.6, 42.6, 1.0),
```

Виды стен (`kind`):

| Вид | Что это |
|---|---|
| `w` | Белая перегородка до потолка |
| `g` | Стекло в чёрных рамах |
| `c` | Стена ядра |
| `lib` | Стена фонда библиотеки |
| `pink` | Розовый туф |
| `mint`, `lilac` | Сплошной парапет 1,05 м |
| `glassrail` | Стеклянное ограждение |

Отделка лицевой стороны задаётся через `extra.f`: `girih`, `pixel`, `lime`, `play`, `black`, `navy`, `portraits`.

Виды дверей: `door`, `double`, `glass`, `open` (проём на всю высоту).

> **Проходимость.** Капсула игрока шириной 0,56 м: проёмы делайте не уже 0,8 м. Проверьте результат через `node tools/walk-test.mjs` и `node tools/nav-check.mjs` (см. [Проверка](#проверка)).

### Новый тип зоны со своей мебелью

Тип зоны выбирает наполнение в `zoneContents()` ([`src/build/interior.js`](../src/build/interior.js)):

```js
// interior.js → zoneContents(): новая ветка
case 'reading': readingRoom(ctx, zn); ceilingLights(ctx.lights, zn.rect, top - 0.6, 'led', 3.0); break;

// interior.js: функция наполнения
function readingRoom(ctx, zn) {
  const { I, z, R } = ctx;                        // I — инстансер на уровень, R — детерминированный random
  const [u0, v0, u1, v1] = zn.rect;
  for (let u = u0 + 1.2; u < u1 - 1; u += 2.4) {
    for (let v = v0 + 1.2; v < v1 - 1; v += 2.0) {
      I('beanbag', F.beanbagGeo, 'nylon').push(mtx(u, v, z, R() * Math.PI), '#2fd0b3');
    }
  }
}
```

Добавьте название типа в `TYPE_NAMES` (`main.js`), например `reading: 'Читальный зал'`: оно нужно инспектору и редактору. Заливку на плане задаёт `TYPE_FILL` (`src/ui/plan.js`), цвет на мини-карте прогулки — `TONE` (`src/lib/walk.js`).

## Рецепты: мебель, материалы, картинки

### Новый предмет мебели

Геометрию собирайте из примитивов в [`src/build/furniture.js`](../src/build/furniture.js). Функция `part(геометрия, цвет)` красит части вершинными цветами, `merge()` склеивает их в одну геометрию:

```js
// furniture.js
export function lecternGeo() {
  return merge([
    part(box(0.6, 1.05, 0.45, 0, 0.525, 0), 0x2b2f36),     // корпус
    part(box(0.66, 0.04, 0.5, 0, 1.07, -0.02), 0x2fd0b3),  // столешница
  ]);
}
// в функции зоны (interior.js): один InstancedMesh на тип на уровень
I('lectern', F.lecternGeo, 'fabric').push(mtx(u, v, z, Math.PI));
```

Для многоцветной геометрии нужен материал с вершинными цветами: `fabric`, `nylon`, `monitor`, `chairBlack` и т. п. (`vc(...)` в `materials.js`). Цвет второго аргумента `push(matrix, color)` красит весь экземпляр.

Мелочь вроде стульев и мониторов не должна мешать ходьбе. Добавьте имя инстанса в `SKIP_INST` ([`src/lib/collision.js`](../src/lib/collision.js)) или пометьте объект `userData.noCollide = true`.

### Новый материал

Добавьте фабрику в таблицу материалов [`src/lib/materials.js`](../src/lib/materials.js) (ключ → функция, создающая материал) и берите материал через `mats.get('ключ')`. Материалы создаются один раз и переиспользуются. Наружные ключи перечислите в `EXTERIOR`: они отражают небо, а интерьерные — светлую «комнату».

### Новая картинка, экран или вывеска

Изображения рисуются на canvas при загрузке: текстуры поверхностей лежат в [`textures.js`](../src/lib/textures.js), «картины» — в [`art.js`](../src/lib/art.js). Образец — `slide()` в `textures.js` (слайд экрана лектория):

```js
export function slide(title = 'SCHOOL 21', sub = 'это бесплатная школа цифровых технологий') {
  const [c, ctx] = canvas(1024, 576);
  // ...рисуем градиент, текст и карточки...
  return tex(c, [1, 1], { repeat: false });
}
```

Шрифты Unbounded, Onest и JetBrains Mono уже загружены к моменту отрисовки. Чужие фото и логотипы в репозиторий не кладём, всё рисуем сами.

## Рецепты: люди

Люди собраны в [`src/build/people.js`](../src/build/people.js). Модели — Quaternius «Ultimate Modular Men/Women» (CC0) из `assets/people/`. Каждый человек — один `SkinnedMesh` с вершинными цветами: одежда перекрашивается без текстур, на человека уходит один вызов отрисовки.

**Роли** (`ROLES`):

| Роль | Кто это |
|---|---|
| `peer21` | Студент в форме School 21: чёрное или белое со знаком «21» на груди |
| `peer` | Студент в обычной одежде |
| `adm` | Команда кампуса, форма с бирюзой |
| `guest` | Гость в костюме или платье |

`w` — вес роли при случайном выборе, `types` — допустимые модели, `top` и `pants` — палитры одежды.

**Позы** (`setPose`):

| Поза | Что делает |
|---|---|
| `stand` | Стоит |
| `talk` | Разговаривает |
| `wave` | Машет |
| `walk` | Идёт |
| `host` | Ведёт |
| `sit` | Сидит |
| `sitType` | Печатает сидя |
| `sitClap` | Хлопает сидя |
| `clap` | Хлопает стоя |
| `cheer` | Ликует |

Позы сидя, хлопки и ликование запекаются из костей при загрузке (`bakeClips`). Подбирать новые удобно в `tools/people-lab.html`.

```js
// people.js → populateNormal(): ещё одна группа беседующих — [уровень, u, v, отметка пола (необязательно)]
const groupsAt = [ /* … */ ['L2', 28.0, 40.0] ];

// …и ещё один прохожий: [уровень, отметка пола, точки маршрута] — ходит туда-обратно
const walks = [ /* … */ ['L2', 4.5, [[30.0, 39.5], [14.0, 39.5]]] ];

// новая роль — сотрудник в бирюзовом худи
{ id: 'staff', w: 0.5, types: ['m_hoodie', 'w_casual'], form: true, top: ['#2fd0b3'], pants: ['#22262c'] },
```

Места у столов, стулья ивент-холла и подушки амфитеатра берутся из `SEATS`, их заполняет `interior.js` при расстановке мебели. Новая мебель для сидения добавляется туда же: `SEATS.desk.push({ u, v, z, h, face, level })`.

**Новая модель человека:**

1. Скачайте модель Quaternius в glTF (CC0, [quaternius.com](https://quaternius.com) или [poly.pizza](https://poly.pizza/u/Quaternius)).
2. Ужмите её: `python3 tools/glb_strip.py in.glb assets/people/имя.glb`. Без `--keep` анимации удаляются, они общие и лежат в `anims.glb`.
3. Добавьте имя в `TYPES` и соответствие «Часть:Материал → слот» в `SLOTS`.
4. Проверьте позы в лаборатории и в модели.

## Рецепты: праздник, свет, камера

- **Праздничное оформление** живёт в [`src/build/party.js`](../src/build/party.js). Новая деталь добавляется через `add('ключ', объект)`. Ключ — часть для разреза:
  - `B1`, `L1`, `M`, `L3`, `atr` (атриум) — уровни;
  - `ext` — снаружи, `roof` — крыша, `band3` — пояс 3 этажа.

  При разрезе `setCut` прячет части выше выбранного уровня. Декор не должен мешать прогулке, поэтому вся группа праздника помечена `noCollide`.
- **Слайды на экранах** ивент-холла и амфитеатра рисует `birthdayScreen()` в [`art.js`](../src/lib/art.js). Это три слайда по 5,5 с: поздравление, «2 года», «Спасибо». Меняйте текст и вёрстку в функции `slide(i, a, t)`.
- **Время суток:** таблица `TIMES` в [`main.js`](../src/main.js). Скопируйте ближайший пресет и поменяйте его: азимут и высота солнца, его яркость и цвет, экспозиция, свечение окон и экранов, сила bloom. Пресет `dusk` (синий час) доступен через `__s21.applyTime('dusk')`.
- **Ракурсы:** `PRESETS` в `main.js`, например `{ id: 'cafe', name: 'Кухня 3 этажа', pos: [u, v, z], tgt: [u, v, z], cut: null, inside: true }`. Позицию удобно подбирать в консоли через `__s21.camera` и `__s21.controls.target` (в координатах сцены, перевод — в AGENTS.md).

## Проверка

Скрипты лежат в `tools/` и работают через headless Chrome:

```bash
python3 -m http.server 5321 &      # сервер модели
cd tools && npm install && cd ..   # один раз: puppeteer-core (Chrome должен быть установлен; путь — CHROME=…)

node tools/walk-test.mjs           # 29 маршрутов прогулки: вход, все лестницы, кластеры, санузлы, пандус
node tools/nav-check.mjs           # заливка проходимости: обрывы, отрезанные места, закрытые проёмы
node tools/perf.mjs                # кадры/с, вызовы отрисовки и треугольники в типовых видах
node tools/shot.mjs out/x "cluster:11.6,45.3,6.3,11.6,56.8,5.3,54" "plan:-"
```

Ракурс для `shot.mjs` задаётся как `имя:u,v,z,цель_u,цель_v,цель_z[,fov][,разрез]`. Переменные окружения:

| Переменная | Что задаёт |
|---|---|
| `TIME=dusk` | Время суток |
| `PARTY=1` | Праздник |
| `PEOPLE=0`, `CROWD=2` | Без людей или плотнее толпа |
| `UI=1` | Оставить интерфейс в кадре |
| `CLICK=v-plan` | Нажать кнопки интерфейса по id |
| `EVAL='…'` | Выполнить JS в странице |

Так сняты все картинки в README.

## Своя копия и деплой

Сборки нет, поэтому подойдёт любой статический хостинг.

- **Vercel:** импортируйте репозиторий: Framework «Other», без команды сборки, выходная папка — корень. Из консоли: `vercel deploy --prod --yes`. `vercel.json` задаёт кэш для `src/`, а `.vercelignore` не выкладывает `tools/`, `docs/` и Markdown.
- **GitHub Pages:** включите Pages для ветки `main`, папка `/`. Пути в проекте относительные, так что модель работает и из подпапки.
- **Локально без интернета** не заработает: three.js и шрифты грузятся с CDN.
